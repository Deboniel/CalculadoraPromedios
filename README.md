CALCULADORA DE PROMEDIOS
Esta aplicación es una calculadora de promedios muy sencilla y útil que te permite ingresar tres notas y obtener
al instante el promedio exacto con decimales. La interfaz es limpia y agradable, con un fondo celeste, un título 
destacado y botones fáciles de usar, para que cualquiera pueda calcular sus promedios sin complicaciones. 
Además, si se ingresa un valor incorrecto, la app muestra un mensaje para avisarte y evitar errores. Fue desarrollada en Android Studio
usando Kotlin y aprovecha ViewModel y LiveData para manejar los datos de manera ordenada, logrando que todo funcione rápido y de forma confiable.
